# PetDogs Frontend

Interface web da Estética PetDogs, construída com React, TypeScript, Vite e Tailwind CSS.

## Executar localmente

```bash
npm install
npm run dev
```

A API é acessada pela URL definida em `VITE_API_URL` (por padrão, `http://localhost:3000`).

## Verificações

```bash
npm run lint
npm run build
```
